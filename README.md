# Java File Handling Demo

## Objective

Learn Java file handling using FileReader and FileWriter and manage the project using Git and GitHub.

## Features

* Writes student information to a text file
* Reads data from the text file
* Demonstrates exception handling using try-catch
* Uses FileWriter and FileReader classes

## Technologies Used

* Java
* Git
* GitHub

## How to Run

1. Compile the program:

javac FileHandlingDemo.java

2. Run the program:

java FileHandlingDemo

Data written successfully.
